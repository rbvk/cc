🔑 Integración de solo lectura (opcional)

Para mostrar indicadores automáticos, crea un OAuth Client ID (Web application) en Google Cloud y autoriza el origen https://cc.rodolfovalle.com. Habilita Google Sheets API y Calendar API. Configura la pantalla de consentimiento en modo Testing, con tu cuenta como único test user.

El Client ID y los enlaces se guardan solo en este navegador. Los tokens de Google permanecen en memoria y desaparecen al recargar. La autorización real de los datos la determinan Google y los permisos de cada hoja.
